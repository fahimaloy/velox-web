这个页面最有用的事情是告诉你 **什么不会工作**，这样你就不会围绕它设计。

## 声明的非目标

这些是决定，不是遗漏。

| 非目标 | 原因 |
| --- | --- |
| DOM 兼容性 | 无虚拟文档。树仅为一帧存在。 |
| 浏览器 API | 无 `window`、无网络栈、无 `fetch`。 |
| 服务端渲染 | CPU 光栅 + 窗口就是产品。 |
| WebAssembly 目标 | Velox 是原生 Rust。WASM 移植需要不同架构。 |
| React/Vue/Svelte 互操作 | 无桥接。Velox 是独立框架。 |

## 考虑中的功能 (未承诺)

| 功能 | 状态 | 备注 |
| --- | --- | --- |
| 命名插槽 (`v-slot:foo`) | 文法中没有 | 需要解析器扩展 |
| `:key` 属性 (协调) | 解析，未遵守 | 无保留树无法做 keyed diff |
| 函数 props | 不可能 | Rust 类型系统无法泛型表示闭包 |
| `emit()` 运行时路径 | 编译，被丢弃 | 事件分发器无 `emit` 入口点 |
| `@media` / `@supports` | 解析，永不求值 | 无媒体查询引擎 |
| 自定义属性 (`var(--x)`) | 解析，惰性 | 无替换步骤 |
| `+` / `~` 组合器 | 作为标签名解析 | 永不匹配 |
| `:hover` / `:focus` 伪类 | 解析，部分 | 仅在静态样式表工作，无动态 hover 状态 |

## 永远不会来的

- **Virtual DOM / diffing** — 架构上互斥。见 `docs/RECONCILER.md`。
- **服务端渲染** — 无 HTML 输出管线。
- **无障碍树** — 无 `accesskit` / `AccessKit` 集成。
- **运行时国际化** — i18n 是编译时的 (像这个网站)。

## 里程碑 (暂定)

| 版本 | 重点 |
| --- | --- |
| 0.1 | 基础: 信号、组件、基础布局、CPU 光栅 |
| 0.2 | 路由、HTTP、表单处理、更好的工具 |
| 0.3 | GPU 渲染路径 (可选)、开发工具、性能分析器 |
| 1.0 | API 稳定性、文档完整性、迁移指南 |

> **注意:** 此时间线未承诺。它仅反映当前思路。
