## velox init

```bash
velox init <name>
```

একটি কーゴ প্রজেক্ট স্ক্যাফোল্ড করে `Cargo.toml`、`build.rs`、`assets/` এবং `src/{App.vx,main.rs}` সহ।

| ফ্ল্যাগ | প্রভাব |
| --- | --- |
| `--name <name>` | ক্রেটের নাম ওভাররাইড করুন |
| `--v <0.1.0>` | ভার্সন স্ট্রিং |
| `--edition <2024>` | রাস্ট এডিশন |
| `--force` | এক্সিস্টিং ফাইল ওভাররাইট করুন |
| `--dry-run` | প্ল্যান প্রিন্ট করুন, কিছুই লিখবেন না |

## velox build

```bash
velox build [--release]
```

প্রজেক্ট কেটি করে। `--release` অপ্টিমাইজেশন সক্ষম করে।

| ফ্ল্যাগ | প্রভাব |
| --- | --- |
| `--release` | রিলিজ মোডে বিল্ড করুন |
| `--target <triple>` | ক্রস-কোম্পাইলেশন টার্গেট |
| `--no-default-features` | ডিফল্ট ফিচার ডিজেবল করুন |

## velox dev

```bash
velox dev [--port <3000>] [--open]
```

ফাইল ওয়াচারের সাথে একটি ডেভ সার্ভার চালায়। হট রিলোড `.vx` এবং রাস্ট ফাইলের পরিবর্তনে ট্রিগার হয়।

| ফ্ল্যাগ | প্রভাব |
| --- | --- |
| `--port <3000>` | পোর্ট সেট করুন |
| `--open` | ব্রাউজার খুলুন |
| `--no-hmr` | হট মডিউল রিপ্লেসমেন্ট ডিজেবল করুন |

## velox run

```bash
velox run [--release] [-- <args>...]
```

বিল্ড করা বাইনারি এক্সিকিউট করে। `--` এর পরের আর্গুমেন্টগুলো প্রোগ্রামে পাস হয়।

## velox lint

```bash
velox lint [--fix]
```

সহজ `.vx` ফাইলগুলোর উপর লিন্টার চালায়: সিনট্যাক্স, অযোগ্য অ্যট্রিবিউট, অপ্রয়োজনীয় ইম্পোর্ট। `--fix` অটো-ফিক্সের চেষ্টা করে (সীমিত)।

## velox add

```bash
velox add <feature>
```

একটি ফিচার/ডিপেন্ডেন্সি যোগ করে প্রজেক্টে। বর্তমানে সাপোর্টেড: `router`, `http`, `serde`।

## velox version

```bash
velox version
```

ইনস্টল করা velox CLI-এর ভার্সন প্রিন্ট করে।
