কম্পোনেন্ট হল `.vx` ফাইল। প্যারেন্ট চাইল্ডকে ইম্পোর্ট করে; কোডজেন বিল্ড টাইমে চাইল্ডের VNode ট্রি প্যারেন্টের ভেতরে ইনলাইন করে।

## প্রপস

চাইল্ড সেগুলো একটি `Props` স্ট্রাক্টে ডিক্লেয়ার করে:

```html
<script setup>
pub struct Props {
    pub value: String,
    pub placeholder: String,
}

pub struct State {
    pub props: Props,
}
</script>
```

প্যারেন্ট সেগুলো বাইন্ড করে:

```html
<TodoInput :value="draft" :placeholder="input_placeholder" />
```

প্রপস টাইপ-চেকড। একটি মিসিং প্রপ একটি কম্পাইল এরর, রানটাইম সারপ্রাইজ নয়।

## Emits

<Callout type="danger" title="emit() কম্পাইল হয় কিন্তু কিছুই করে না">
নামটি বাউন্ড থাকে, বডি একটি নো-অপ। তাই `<Confirm @confirm="…">` নিষ্ক্রিয়। এটি একটি ডকুমেন্টেড লিমিটেশন — ইভেন্ট ডিসপ্যাচার `emit` কল পাথ না থাকায় এটি ড্রপ করে।
</Callout>

```html
<script setup>
pub struct Props {
    pub on_confirm: Option<fn()>,
}
</script>
```

প্যারেন্ট লিখে:

```html
<Confirm @confirm="handle_confirm" />
```

কম্পাইলার স্লট বাইন্ডিং এনকোড করে, কিন্তু রানটাইমে হ্যান্ডলার কল পাথ অনুপস্থিত।

## স্লটস

<Callout type="danger" title="নেইমড স্লটস অনুপস্থিত">
`v-slot` গ্রামারেই নেই। `<slot>` এলিমেন্ট পার্স হয় কিন্তু কোনো ডিস্ট্রিবিউশন লজিক নেই — চাইল্ড কন্টেন্ট সরাসরি রেন্ডার হয়।
</Callout>

ডিফল্ট স্লট কন্টেন্ট ইনলাইন হয়। নেইমড স্লট (`v-slot:foo` বা `#foo="slotProps"`) একটি ভবিষ্যত ফিচার।

## v-model (টু-ওয়ে বাইন্ডিং)

```html
<input v-model="name" />
```

এটি এক্সপ্যান্ড হয়:
- `:value="name"`
- `@input="__vmodel_set_name"`

জেনারেটেড সেটার `State`上的 একটি `&self` মেথড, ইভেন্ট ডিসপ্যাচারের সাথে ওয়ায়ার্ড।

## কম্পোনেন্ট কম্পোজিশন

যেহেতু কোডজেন ইনলাইন করে, একটি প্যারেন্ট তার চাইল্ডের সিগন্যাল/কম্পিউটেড/ইফেক্ট ডায়রেক্টলি এক্সেস করতে পারে যদি চাইল্ড এক্সপোর্ট করে। কোনো রানটাইম প্রপ ড্রিলিং নেই — সzième প্রাইভেট থাকার প্রয়োজন নেই।
