ভেলক্স Skia-তে রাস্টারাইজ করে। একটি GPU পাথ আছে, তবে সেটি অপ্ট-ইন এবং আনফিনিশড। যা ডিফল্টভাবে শিপ করে তা হল CPU।

<Callout type="note" title="একটি লিমিটেশন নয় যার জন্য মাফী চাইতে হবে">
CPU রাস্টারাইজেশন **ডিলিবারেট ডিফল্ট**: এটি গোল্ডেন-ইমেজ টেস্টকে ডিটারমিনিস্টিক করে, বিল্ডকে EGL এবং উইন্ডো-সিস্টেম ডিপেন্ডেন্সি থেকে মুক্ত রাখে, এবং একটি হেডলেস CI মেশিনে সেম যে ভাবে চলে। GPU রেন্ডারিং একটি কনফিগ ফ্ল্যাগ, আর্কিটেকচারাল কমিটমেন্ট নয়।
</Callout>

## কেন CPU?

1.  **ডিটারমিনিস্টিক আউটপুট** — একই ইনপুট == একই পিক্সেল, সব জায়গায়। কোনো GPU ড্রাইভার ভারিয়েশন নেই।
2.  **হেডলেস CI-ফ্রেন্ডলি** — কোনো EGL/GBM/Wayland/X11 রানটাইম প্রয়োজন নেই। এটি একটি সার্ভারে ঠিক ভাবে চলে।
3.  **নূনতম ডিপেন্ডেন্সি** — শুধু `skia-safe` (স্ট্যাটিক্যালি লিঙ্কড)। কোনো `wgpu`/`glow`/`ash` চেইন নেই।
4.  **স্পষ্ট পারফরম্যান্স মডেল** — আপনি জানেন আপনি কী পাচ্ছেন। কোনো সার্প্রাইজ GPU থ্রাটলিং নেই।

## রেন্ডার পাইপলাইন (প্রতি ফ্রেম)

```
┌─────────────┐
│  সিগন্যাল    │  ──►  ডার্টি চেক
│  পরিবর্তন   │
└──────┬──────┘
       ▼
┌─────────────┐
│  render()   │  ──►  ফ্রেশ VNode ট্রি (ইনলাইনড চাইল্ডসহ)
│  কল        │
└──────┬──────┘
       ▼
┌─────────────┐
│  কম্পিউট    │  ──►  ব্লক + ফ্লেক্স লেআউট
│  লেআউট     │       জিওমেট্রি (velox-dom)
└──────┬──────┘
       ▼
┌─────────────┐
│  কম্পিউট    │  ──►  সিলেক্টর ম্যাচ + ক্যাসকেড
│  স্টাইল     │       রেজলিউশন (velox-style)
└──────┬──────┘
       ▼
┌─────────────┐
│  Skia       │  ──►  রিয়ুজড সারফেসে রাস্টারাইজ
│  রাস্টার     │       প্রেজেন্ট
└─────────────┘
```

**প্রতিটি স্টেজ প্রতিটি ফ্রেমে শূন্য থেকে চলে।** কোনো কিছু আগের ফ্রেমের সাথে ডিফ করা হয় না। কোনো রিটেইন্ড ট্রি নেই।

## সারফেস রিয়ুজ

রেন্ডারার একটি `skia_surface::Surface` বফার করে। যদি ভিউপোর্ট সাইজ বদলায়, এটি রি-অ্যালোকেট করে; অন্যথায় এটি রিয়ুজ হয়। এতে alokeshন চার্ন এড়ায়।

## GPU পাথ (এক্সপেরিমেন্টাল)

```bash
velox build --features gpu
```

এটি `wgpu` + `skia-safe` এর GPU ব্যাকএন্ড ব্যবহার করে। এটি ডিফল্ট নয় কারণ:
- ড্রাইভার ক্র্যাশ টেস্টকে ফ্ল্যাকি করে
- CI-এ ভালোভাবে কাজ করে না
- সব প্ল্যাটফর্মে এখনও পুরোপুরি ফিচার-পারিটি নেই

## পারফরম্যান্স নোট

| মেট্রিক | সাধারণ রেঞ্জ |
| --- | --- |
| ফ্রেম টাইম (সিপিইউ, ১০৮০পি, সিম্পল ইউআই) | ১-৩ মিসেকেন্ড |
| মেমরি (সারফেস + বফার) | ১৫-৩০ এমবি |
| বিল্ড সাইজ (সিপিইউ-ওনলি) | ~৪ এমবি স্ট্রিপড |

আপনার ইউআই যদি ৬০ FPS-এ চলতে না পারে, প্রোফাইলার দেখান `velox_renderer::present` — সাধারণত লেআউট বা টেক্সট র‍্যাপিং, রাস্টারাইজেশন নয়।
