এই পৃষ্ঠাটি যা সবচেয়ে বেশি উপকারী করতে পারে তা হল আপনাকে বলে দেয়া যে **ক्या কাজ করবে না**, যাতে আপনি সেটি ছাড়া ডিজাইন করুন।

## ডিক্লেয়ারড নন-গোলস

এইগুলো ডিসিশন, অনুপস্থিতি নয়।

| নন-গোল | কেন |
| --- | --- |
| DOM কম্প্যাটিবিলিটি | কোনো ভার্চুয়াল ডকুমেন্ট নেই। ট্রি শুধু একটি ফ্রেমের জন্য এক্সিস্ট করে। |
| ব্রাউজার APIs | কোনো `window`, কোনো নেটওয়ার্ক স্ট্যাক, কোনো `fetch` নেই। |
| সার্ভার রেন্ডারিং | CPU রাস্টার এবং একটি উইন্ডোই প্রডাক্ট। |
| WebAssembly টার্গেট | ভেলক্স নেটিভ রাস্ট। WASM পোর্টে একটি ভিন্ন আর্কিটেকচার লাগবে। |
| React/Vue/Svelte ইন্টারঅপ | কোনো ব্রিজ নেই। ভেলক্স একটি স্ট্যান্ডঅ্যালোন ফ্রেমওয়ার্ক। |

## যেসব ফিচার আন্ডার কনসিডারেশন (কমিটেড নয়)

| ফিচার | স্ট্যাটাস | নোটস |
| --- | --- | --- |
| নাম ইনডেন্টেড স্লটস (`v-slot:foo`) | গ্রামারেই নেই | পার্সার এক্সটেনশন প্রয়োজন |
| `:key` অ্যট্রিবিউট (রিকন্সিলিয়েশন) | পার্স হয়, অনহোনourd | একটি রিটেইন্ড ট্রি ছাড়া কীড ডিফ অসম্ভব |
| ফাংশন প্রপস | অসম্ভব | রাস্টের টাইপ সিস্টেম একটি ক্লোজারকে জেনেরিকভাবে রিপ্রেজেন্ট করতে পারে না |
| `emit()` রানটাইম পাথ | কম্পাইল হয়, ড্রপ হয় | ইভেন্ট ডিসপ্যাচারের কোনো `emit` এন্ট্রি পয়েন্ট নেই |
| `@media` / `@supports` | পার্স হয়, কখনো ইভ্যালুয়েট হয় না | কোনো মিডিয়া কোয়েরি ইঞ্জিন নেই |
| কাস্টম প্রপার্টি (`var(--x)`) | পার্স হয়, নিষ্ক্রিয় | কোনো সাবস্টিটিউশন স্টেপ নেই |
| `+` / `~` কম্বিনেটর | ট্যাগ নাম হিসেবে পার্স হয় | কখনো ম্যাচ করে না |
| `:hover` / `:focus` pseudo-ক্লাস | পার্স হয়, আংশিক | শুধু স্ট্যাটিক স্টাইলশিটেই কাজ করে, ডাইনামিক হোভার স্টেট নেই |

## কী কখনো আসবে না

- **Virtual DOM / diffing** — আর্কিটেকচারি প্রতিবন্ধী। `docs/RECONCILER.md` দেখুন।
- **Server-side rendering** — কোনো HTML আউটপুট পাইপলাইন নেই।
- **Accessibility tree** — কোনো `accesskit` / `AccessKit` ইন্টিগ্রেশন নেই।
- **Internationalization runtime** — i18n কম্পাইল-টাইম (এই সাইটের মতো)।
